Website Screenshot API & URL to PDF API

A website screenshot API and URL to PDF API on headless Chromium. Send URLs or raw HTML, get full-page screenshots (PNG/JPEG) and PDFs. Bulk, pay per result, failed pages are never billed.

Try it on Apify: pennydata/shot-pdf

Features

  • Full-page website screenshot or viewport only
  • URL to PDF (A4, Letter, landscape, print backgrounds)
  • HTML to PDF from inline HTML
  • Height limit, clip region, hide sticky headers and cookie bars, lazy-load scrolling
  • Many URLs per call; failed URLs return an error row and cost nothing

curl: website screenshot API

export APIFY_TOKEN=your_token_here
curl -X POST "https://api.apify.com/v2/acts/pennydata~shot-pdf/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"urls":[{"url":"https://example.com"}],"mode":"screenshot","fullPage":true}'

curl: URL to PDF API

curl -X POST "https://api.apify.com/v2/acts/pennydata~shot-pdf/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"urls":[{"url":"https://en.wikipedia.org/wiki/Web_scraping"}],"mode":"pdf","pdfFormat":"A4"}'

Node.js (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });
const run = await client.actor('pennydata/shot-pdf').call({
  urls: [{ url: 'https://example.com' }],
  mode: 'pdf',
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

Python

import os, requests

resp = requests.post(
    "https://api.apify.com/v2/acts/pennydata~shot-pdf/run-sync-get-dataset-items",
    params={"token": os.environ["APIFY_TOKEN"]},
    json={"urls": [{"url": "https://example.com"}], "mode": "screenshot"},
    timeout=300,
)
print(resp.json())

Input options

urls, htmlDocuments, mode (screenshot / pdf / both), format, fullPage, maxHeight, clip, hideFixedElements, scrollTimeoutSecs, viewportWidth, viewportHeight, waitUntil, delayMs, waitForSelector, pdfFormat, pdfLandscape, pdfPrintBackground. See the README and the full schema.
