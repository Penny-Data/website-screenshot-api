URL to PDF API on Apify: convert web pages to PDF with one HTTP call

Disclosure: I publish pennydata/shot-pdf, so this is a vendor page. It was written with AI assistance (Claude) and is not affiliated with Apify.

What it is

pennydata/shot-pdf is an Apify actor that renders public web pages (or HTML you send) in headless Chromium and returns a PDF, a PNG/JPEG screenshot, or both. You call it over the Apify REST API, so it fits cron jobs, backends and no-code tools.

Call it with curl

export APIFY_TOKEN=your_token_here
curl -X POST "https://api.apify.com/v2/acts/pennydata~shot-pdf/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"urls": [{"url": "https://example.com"}], "mode": "pdf", "pdfFormat": "A4", "pdfPrintBackground": true}'

Input example

{
  "urls": [
    {
      "url": "https://example.com"
    }
  ],
  "mode": "pdf",
  "pdfFormat": "A4",
  "pdfPrintBackground": true
}

Other input fields include htmlDocuments (HTML string to PDF), fullPage, waitUntil, delayMs and hideSelectors.

Output

Each dataset item has the input URL and a link to the stored PDF or image; failed URLs return an error row. Run a small sample first and check the fields before wiring it into production.
